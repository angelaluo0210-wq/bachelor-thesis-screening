The matrix gives the exact per-run path rather than the shorthand above. Rows marked **Partial** have a traceable result but an incomplete historical code/environment/log chain. Four nonselected formal strategy rows are **Missing** because their original per-record predictions, checkpoints and run logs are absent. No row is called Complete merely because a current checkout could rerun it.

## Pooling public copies

Each public Pooling prediction CSV has exactly 22,397 rows in the original Validation order. `source_row_index` is zero-based and can be joined to the local `data/processed/splits/validation.csv`; review, label, probability and decision are retained. Article titles, PMID, DOI and OpenAlex ID are omitted from the public copy. Before copying, all four original prediction files were checked row-by-row against the source Validation CSV for review, label, title and available identifiers. The public configuration, summary and log copies replace historical absolute working paths with `<PROJECT_ROOT>`; original files are untouched. `source_manifest.json` gives SHA-256 hashes for every original and names the corresponding copy. Checkpoint binaries were not copied.

## Input and checkpoint identity

Use `input_sha256.csv` for the local Train, Validation, Test and criteria inputs; use `checkpoint_sha256.csv` for Pooling, selected/supplementary adapters, TF-IDF objects and PubMedBERT base weights. On Windows PowerShell, compare a local file with `Get-FileHash -Algorithm SHA256 -LiteralPath <path>`. `missing` is an absent expected file; `not_recorded` is an unknown historical value. The hash is an identity check, not proof that the file was used by a particular unlogged historical process.

## Historical Qwen public copies

Nine JSON files under `qwen_historical_public/` are **redacted copies**, not original run records. `qwen_historical_sha256.csv` maps every local original path and SHA-256 to its public-copy path and SHA-256. Each copy carries `_public_copy` metadata, including the original file hash and the hash of the historical endpoint. The public `configuration_fingerprint` is recalculated for the redacted configuration; the original fingerprint is retained separately. The original nine files are neither imported nor modified in this branch. The public copies preserve model and request parameters, run status, prediction references and recorded input hashes.
