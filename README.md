# Thesis experiment reproducibility

This is an **uncommitted local delivery branch** based directly on `origin/main` (`596fcc609c00d63859700868a6770d4afaa2e9aa`). It imports selected reviewed files from the local historical `work` checkout; it does not merge or cherry-pick that branch's endpoint-bearing commits.

The [experiment index](results/reproducibility/README.md) maps thesis results to [provenance CSV](results/reproducibility/experiment_provenance.csv) and [JSON](results/reproducibility/experiment_provenance.json), [checkpoint hashes](results/reproducibility/checkpoint_sha256.csv), [input hashes](results/reproducibility/input_sha256.csv), [historical environment evidence](results/reproducibility/environment_summary.md), [missing artifacts](results/reproducibility/missing_artifacts.md), the [delivery safety report](results/reproducibility/delivery_safety_report.md), and the [reviewed file inventory](results/reproducibility/delivery_file_manifest.csv). Nine Qwen historical JSON records have separately labeled [public copies and original/public SHA-256 mapping](results/reproducibility/qwen_historical_sha256.csv). Their original bytes remain only in the local historical checkout.

The Qwen client takes its actual URL from `QWEN_BASE_URL` when set and its API key from `DASHSCOPE_API_KEY`. Without `QWEN_BASE_URL`, it uses the provider's shared Beijing OpenAI-compatible endpoint. **The completed historical Qwen runs used a workspace-dedicated endpoint**, so the shared default is a different routing configuration; set the historical URL privately to reproduce that routing. Public run configuration serialization records an endpoint category and SHA-256, not the workspace ID or URL.

To regenerate the index from locally held raw evidence, set `REPRO_SOURCE_ROOT` to the historical checkout, run `python scripts/prepare_qwen_public_records.py --source-root <historical-checkout>`, then run `python scripts/build_reproducibility_index.py --refresh-generated`. Both commands read existing files only and write public copies/indexes in this delivery worktree. They do not train, infer, call the Qwen API, or change experiment metrics. A public clone alone cannot reconstruct local-only split data, model weights, missing historical runs, or original private configurations; their identities and gaps are documented in the index.

Four nonselected formal training strategies still lack original per-record predictions, checkpoints and logs. The index labels these runs `Missing` rather than constructing substitutes.
